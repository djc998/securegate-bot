Quick Start Guide

Deploying SecureGate in your Telegram group takes less than 60 seconds.

  1. Add the bot to your group.
  2. Promote it to Administrator with the Restrict Members privilege.
  3. Type /setup in the group chat.

Once setup is complete, every new member joining will be instantly muted and presented with a mathematical captcha inline.

Command Reference

Below is a list of commands and who can execute them.

/setup

Required Permission: Group Admin

Initializes the group in the database and assigns you as the registered owner. Must be run in the target group chat.

/settings

Required Permission: Group Owner

Must be run in a private DM with the bot. Opens the inline configuration dashboard where you can adjust the verification timeout duration (e.g., 30s, 5m, 1h) and customize the video prompt.

/premium

Required Permission: Group Owner

Must be run in the target group chat. Dispatches a Telegram Stars checkout invoice to your private DMs to unlock Tier-2 Video Identity Verification.

/verify [@username]

Required Permission: Group Admin

Manually approves a pending user and unmutes them instantly, bypassing the cognitive gate. Can be used by replying to a user's message with `/verify` or by tagging them.

Verification Tiers

Tier 1: Cognitive Math Gate (Free)

Upon joining, members lose all sending permissions. A randomized addition puzzle is presented in chat with 4 multiple-choice options. Incorrect answers or timeouts result in an automatic ban/unban (kick).

Tier 2: Identity Video Gate (Premium)

After solving the math puzzle, premium channels intercept the unmute action. The user is provided a URL portal linking to the bot's DMs. They must record or send a brief video message. The video is securely forwarded to the group owner's private inbox with Approve/Reject inline buttons. The user is only unmuted upon manual approval.

Premium Upgrade

Premium is built natively into Telegram via Telegram Stars (XTR). You can start a 1-week free trial directly from the /premium menu or pay a one-time fee to permanently unlock the Video Gate and Dashboard for your specific group chat.
